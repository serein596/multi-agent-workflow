# 多 Agent 协作工作流设计文档

## 1. 系统概述

本项目旨在构建一个具备条件分支与循环修复能力的多智能体协作系统。系统以“代码生成与修复”为业务场景，通过三个 Agent 的协同合作，实现了从需求到高健壮性代码的全自动闭环。
